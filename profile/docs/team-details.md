#### 2. 시각장애인(VoiceOver) 관점 점검 반영 (앱 #82)

| 고친 것 | 내용 |
| --- | --- |
| 허용 창 안내 | "'허용 안 함'은 지나치고 '허용'이나 '확인'에서 두 번 탭" |
| 기다림 진동 | 서버를 기다리는 동안 2초 뒤부터 2.5초마다 짧은 진동, 6초 넘으면 "아직 보고 있어요" |
| 셀카 구도 안내 | 화장 확인 전 멀리/가까이/가운데로 실시간 안내, 8초 못 맞추면 멈추면 찍기 |
| 연결 오류 | 연결 오류는 0.8초 뒤 한 번 더, 서버 오류는 두 번 넣지 않게 다시 안 보냄, 하던 대화 남겨 두기 |
| VoiceOver 이름 | 말하기 영역을 상태별(듣는 중/알아보는 중/말하는 중/말하기)로 짧게 읽기 |
| 구도 삑 소리 | 가운데·알맞은 크기에 가까울수록 소리+진동 간격 1.1초 → 0.15초 |
| 그 밖 | 일정 알림을 누르면 그날 옷 추천으로 시작, 시리 단축어, 잠깐 쉬어, "나중에 할게"로 남은 질문 넘기기 |

점검 문서 12가지 중 11가지를 고쳤어요(9번 매직 탭은 빠짐).
