심청이 아키텍처

앱은 HTTPS로 gateway 하나만 부릅니다. agent가 MCP 서버 다섯에서 날씨·일정·옷 상태·얼굴·옷장을 모아 GPT로 판단해요. 서버는 젯슨 오린 나노 두 대에 나눠 올렸어요. 한 대는 앱 서버와 DB, 다른 한 대는 우리가 학습한 모델을 돌리는 MCP 서버와 학습을 맡아요.

앱 서버

젯슨 오린 나노 8GB, team4

Java 21, Spring Boot 4.0.9, Spring AI 2.0.2. 컨테이너 9개를 Docker Compose로 띄워요.

컨테이너별 메모리 상한합계 5.3GB / 7.6GB

gateway

앱이 부르는 유일한 입구. 로그인과 회원정보, 말 듣기·읽기도 여기서 해요.

  • 경로별로 agent, mcp-schedule에 넘겨요
  • 구글(Firebase) ID 토큰을 확인하고 우리 JWT를 발급 (1시간, 갱신 30일)
  • 회원정보: 이름·호칭·말 빠르기 등, 항목마다 건너뛰기
  • 사용량 제한: 1분에 요청 30번, 사진 10장
  • /stt 음성 인식, /tts 안내 목소리
Spring Cloud Gateway (Web MVC)가상 스레드Nimbus JOSEJdbcClientFlyway
edge-tts 옆 컨테이너 (Python). Edge 목소리 선희·인준·현수를 키 없이 읽어요.

음성 인식은 OpenAI, 목소리는 Azure Speech와 Edge로 보내요

agent

대화를 이끌고 옷을 판단하는 두뇌. MCP 서버 다섯에 클라이언트로 붙어 있어요.

  • 말을 의도로 나눠 옷 추천·옷 확인·색 조합·날씨·얼굴·옷장은 정해진 순서로 도구를 불러요
  • 일정 넣기·지우기 같은 나머지만 GPT가 도구를 골라요
  • 같은 옷인지 애매하면 옷 부분 작은 사진 두 장을 GPT로 비교
